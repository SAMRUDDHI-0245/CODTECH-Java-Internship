# Task 2 – Java REST API Consumer

This Java application consumes a public REST API and displays
user data in a structured format.

## API Used
https://randomuser.me/api/

## Features
- Sends HTTP GET request
- Parses JSON response
- Displays user details in console

## Technologies Used
- Java
- HttpURLConnection
- org.json library

## How to Run
1. Compile:
   javac -cp .;json-20251224.jar RestApiDemo.java
2. Run:
   java -cp .;json-20251224.jar RestApiDemo
